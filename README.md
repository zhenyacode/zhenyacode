## Проекты

### [Текст в динамике](https://kultkod.github.io/text-dynamics.html)

Попытка представить литературное произведение как творческий процесс через историю его изменений: рукописи, авторские правки, редакции и издания.

Проект состоит из нескольких связанных частей:

- **интерактивный плеер** на JavaScript для визуализации переходов и изменений между редакциями;
- **TDJ (Text Dynamics JSON)** — экспериментальный формат представления версий текста, связей между ними и последовательностей правок;
- **TDJ Builder** на Python — пайплайн, который обрабатывает исходные тексты, токенизирует их, автоматически рассчитывает diff между версиями и собирает TDJ.

[Описание проекта](https://kultkod.github.io/text-dynamics.html) · [Демо](https://kultkod.github.io/text-dynamics/) · [Код визуализатора](https://github.com/zhenyacode/text-dynamics) · [TDJ Builder](https://github.com/zhenyacode/tdj_builder)

### [Поиск акростихов в прозе](https://github.com/zhenyacode/acrofinder)

Инструмент и небольшой корпусный эксперимент по автоматическому поиску акростихов в прозаических текстах. Python-утилита ищет последовательности начальных букв предложений, которые могут образовывать скрытые слова и фразы.

Результаты и проблема отделения случайных совпадений от потенциально осмысленных акростихов описаны в статье для «Системного Блока».

[GitHub](https://github.com/zhenyacode/acrofinder) · [Статья в «Системном Блоке»](https://sysblok.ru/philology/chto-takoe-akrostih-i-kak-najti-zashifrovannye-poslanija-v-tekste/)

### [Веб-архив культурных сайтов моего родного города](https://github.com/zhenyacode/ui_archive)

Учебный проект по сохранению цифрового культурного наследия и эксперимент с технологиями веб-архивирования.

Цель — сохранять сайты локальных культурных институций и разбираться на практике, как устроены сбор, хранение и воспроизведение веб-архивов.
